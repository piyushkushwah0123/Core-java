# Core Java Practice Repository

This repository contains Core Java programs and examples covering fundamental to advanced concepts.  
It is designed for strong Java basics, interview preparation, and practical implementation.

## 📌 Topics Covered

- Java Basics (Variables, Data Types, Operators)
- Control Statements (if-else, switch, loops)
- OOP Concepts
  - Encapsulation
  - Abstraction
  - Inheritance
  - Polymorphism
- Constructor & Method Overloading
- Exception Handling
- String Handling
- Collections Framework
- Multithreading
- File Handling
- JDBC Basics
- Java 8 Features (Lambda, Stream API)

## 🛠 Tech Used
- Java
- JDK 8+
- Eclipse / IntelliJ IDEA

## 🎯 Purpose
- Strengthen Core Java fundamentals
- Practice coding problems
- Prepare for interviews
- Understand real-world programming concepts
